# Карго 151 — сайт для клиентов (прототип)

Всё в одном месте, на русском и китайском (переключатель RU / 中文 вверху).

## Для клиента
1. **Получить код**: имя, номер WhatsApp (на него присылаем фото груза и сообщаем о прибытии), город.
2. **Адрес склада** (сразу после регистрации, код `D1600-4567` вверху страницы): выбор Гуанчжоу или Иу (мелкие посылки — только Гуанчжоу), график работы. Кнопка «Скопировать адрес целиком» даёт строку «имя телефон адрес», которую 1688 / Taobao / Pinduoduo сами раскладывают по полям («粘贴地址 / 智能识别»). Есть копирование по отдельным полям.
- **Уже есть код?** — ввести номер WhatsApp, и сайт снова покажет код и адрес.
- **Отследить** — по трек-номерам, с историей статусов.
- **Накладные** — вход по номеру WhatsApp и коду: посылки и список накладных (дата, номер, груз, сумма). Полная накладная повторяет бумажный 货运单, внизу правила перевозки.
- **Услуги, О нас, Полезно знать** (праздники в Китае, упаковка, советы) — тексты меняются в админке.
- Русский и китайский, переключатель RU / 中文.

## Админка (`/admin`)
У каждого сотрудника свой логин и пароль. Владелец входит логином `admin` и паролем `ADMIN_PASSWORD`, остальных заводит сам в «Настройки» → «Сотрудники»:
- **Владелец** — видит всё, единственный видит телефоны клиентов и получателей, меняет настройки, удаляет.
- **Бухгалтер** — загрузка Excel, накладные, цены, статусы, оплата, отчёт, объявления, заявки. Телефонов клиентов и настроек не видит.
- **Менеджер** и **Кладовщик** — только фото с весов к накладным.

Разделы: сводка, клиенты, посылки (ручное добавление и массовая смена статуса), загрузка Excel (шаблон внутри), накладные (номер D1601-1030-4 собирается сам, цена за кг или м³, упаковка, страховка, отметка оплаты; загрузка ежедневной таблицы склада — одна строка = одна накладная, все листы 1月…10月, повторная загрузка обновляет), клиенты со старым кодом (D185, Y58), настройки (склады, график, маркировка, объявление вверху сайта, тексты страниц, пункты выдачи, тариф).

## Запуск
Нужен Node.js 22.5 или новее.
```
npm install
ADMIN_PASSWORD=пароль_владельца SESSION_SECRET=длинная_случайная_строка npm start
```
Сайт откроется на http://localhost:3000. Вход владельца по умолчанию: `admin` / `admin151`. На сервере скрипт установки создаёт свои случайные пароли.
База данных — один файл `cargo151.db` (SQLite) рядом с сайтом, его достаточно копировать для резервной копии.

## Что дальше
- Подтягивать статусы из 151.likerj.com автоматически (нужен доступ к выгрузке или API этой системы).
- Перенести клиентов и коды со старого сайта code.cargo151.com (нужна выгрузка базы).
- Уведомления клиенту в WhatsApp при смене статуса.

## Запуск на сервере (Ubuntu 22.04 / 24.04)
1. Направьте домен (например, `cargo.cargo151.com`) A-записью на IP сервера.
2. Зайдите на сервер под root и выполните одну команду:
```
curl -fsSL https://raw.githubusercontent.com/monblanala-debug/bolysbai/main/deploy/install.sh | bash -s https://github.com/monblanala-debug/bolysbai.git cargo.cargo151.com
```
Скрипт установит Node.js и nginx, запустит сайт как службу, подключит HTTPS и в конце покажет пароли владельца и бухгалтера.
Обновление сайта: та же команда ещё раз (данные и пароль сохраняются). База лежит в `/var/lib/cargo151/cargo151.db`.
