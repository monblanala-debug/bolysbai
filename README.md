# Карго 151 — сайт для клиентов (прототип)

Всё в одном месте, на русском и китайском (переключатель RU / 中文 вверху).

## Для клиента
- **Получить код**: имя, телефон (WhatsApp), город → персональный код (1600, 1601, …).
- **Адреса складов**: один код, два адреса — Гуанчжоу и Иу. Клиент переключает склад и копирует адрес одной кнопкой. Маркировка (唛头) подставляется сама: `D{код}-{последние 4 цифры телефона}`, например `D1600-4567`.
- **Уже есть код?** — поиск по номеру телефона.
- **Отслеживание**: по одному или сразу нескольким трек-номерам, с историей статусов.
- **Личный кабинет** (вход: телефон + код): все посылки, накладные с печатью, можно заранее добавить свой трек.

## Для администратора (`/admin`)
- Сводка по статусам, клиенты (поиск, ссылка в WhatsApp), посылки.
- Добавление посылки вручную и массовая смена статуса.
- **Загрузка Excel**: колонки «Трек, Код клиента, Вес, Мест, Описание, Статус» (заголовки можно на русском или китайском, есть шаблон). Существующие треки обновляются, посылки без зарегистрированного клиента привяжутся автоматически, когда он зарегистрируется.
- **Накладные**: выбрать клиента → отметить посылки → тариф за кг → накладная с суммой, печать, отметка оплаты. Клиент видит её в кабинете.
- **Настройки**: адреса складов (можно добавить ещё), шаблон маркировки, адреса пунктов выдачи по городам, тариф, валюта, с какого номера начинать коды.

Статусы: Ожидается на складе → Принят на складе в Китае → В пути → Граница/таможня → Прибыл в город → Выдан.

## Запуск
Нужен Node.js 22.5 или новее.
```
npm install
ADMIN_PASSWORD=ваш_пароль SESSION_SECRET=длинная_случайная_строка npm start
```
Сайт откроется на http://localhost:3000. Пароль админки по умолчанию `admin151` — обязательно смените через `ADMIN_PASSWORD`.
База данных — один файл `cargo151.db` (SQLite) рядом с сайтом, его достаточно копировать для резервной копии.

## Что дальше
- Подтягивать статусы из 151.likerj.com автоматически (нужен доступ к выгрузке или API этой системы).
- Перенести клиентов и коды со старого сайта code.cargo151.com (нужна выгрузка базы).
- Уведомления клиенту в WhatsApp при смене статуса.

## Запуск на сервере (Ubuntu 22.04 / 24.04)
1. Направьте домен (например, `cargo.cargo151.com`) A-записью на IP сервера.
2. Зайдите на сервер под root и выполните одну команду:
```
curl -fsSL https://raw.githubusercontent.com/<владелец>/<репозиторий>/main/deploy/install.sh | bash -s https://github.com/<владелец>/<репозиторий>.git cargo.cargo151.com
```
Скрипт установит Node.js и nginx, запустит сайт как службу, подключит HTTPS и в конце покажет пароль админки.
Обновление сайта: та же команда ещё раз (данные и пароль сохраняются). База лежит в `/var/lib/cargo151/cargo151.db`.
